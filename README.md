# ⚡ SmartDo – Smart & Stylish Task Manager (PWA)

A modern, fast, and responsive **Progressive Web App (PWA)** built with vanilla HTML, CSS, and JavaScript. It helps users manage daily tasks efficiently with priority levels, progress tracking, and offline support.

## ✨ Features

- **📱 Installable PWA:** Can be downloaded and installed as a standalone Desktop or Mobile App (Create Shortcut).
- **📶 Offline First:** Works fully offline using Service Workers (`sw.js`).
- **🎨 Stylish Dark UI:** Clean, modern, glassmorphic UI built with pure CSS.
- **🏷️ Priority Tags:** Assign Low, Medium, or High priority to tasks.
- **📊 Real-time Progress Bar:** Automatically updates progress based on completed tasks.
- **🔍 Filter Options:** Easily filter tasks by *All*, *Active*, or *Completed*.
- **💾 Local Persistence:** All tasks are saved automatically in `localStorage`.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript (ES6)
- **PWA Integration:** `manifest.json`, Service Worker (`sw.js`)
- **Icons:** FontAwesome v6
